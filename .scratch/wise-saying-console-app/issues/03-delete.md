# 03: 명언 삭제

**What to build:** 사용자가 `삭제?id=N`을 입력하면 해당 명언이 지워지고 `N번 명언이 삭제되었습니다.`를 본다. 없는 번호면 `N번 명언은 존재하지 않습니다.`를, id가 빠졌거나 숫자가 아니면 `id를 정확히 입력해주세요.`를 보고 앱은 계속 동작한다.

부모 스펙: `.scratch/wise-saying-console-app/spec.md`

**Blocked by:** 02 (명언 등록과 목록)

**Status:** done

- [x] 존재하는 번호 삭제 시 성공 메시지가 나오고 목록에서 사라진다
- [x] 없는 번호 삭제 시 `N번 명언은 존재하지 않습니다.`가 나온다
- [x] `삭제`(id 누락)와 `삭제?id=abc`(비숫자)에 `id를 정확히 입력해주세요.`가 나온다
- [x] 삭제 후 새로 등록하면 삭제된 번호가 재사용되지 않는다
- [x] 위 동작을 App 테스트로 검증한다
