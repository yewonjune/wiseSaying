# 02: 명언 등록과 목록

**What to build:** 사용자가 `등록`을 입력하면 `명언 : `, `작가 : ` 순으로 내용과 작가를 입력받고 `N번 명언이 등록되었습니다.`를 본다. `목록`을 입력하면 `번호 / 작가 / 명언` 헤더와 `----------------------` 구분선 아래에 명언이 번호 내림차순으로 `번호 / 작가 / 내용` 형식으로 나온다. 이 티켓에서 명언 엔티티, 메모리 리포지터리, 서비스, WiseSayingController가 처음 생기며 Controller → Service → Repository 흐름이 완성된다.

부모 스펙: `.scratch/wise-saying-console-app/spec.md`

**Blocked by:** 01 (프로젝트 뼈대 — 시작과 종료)

**Status:** ready-for-agent

- [ ] 첫 명언은 1번, 이후 `lastId` 증가로 번호가 부여된다
- [ ] 등록 출력이 명세 예시와 글자 단위로 일치한다
- [ ] 목록은 번호 내림차순으로 출력된다
- [ ] 명언이 없을 때 목록은 헤더와 구분선만 출력한다
