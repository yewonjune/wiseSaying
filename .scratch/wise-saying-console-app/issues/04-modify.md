# 04: 명언 수정

**What to build:** 사용자가 `수정?id=N`을 입력하면 `명언(기존) : <기존 내용>`을 본 뒤 `명언 : `에 새 내용을, `작가(기존) : <기존 작가>`를 본 뒤 `작가 : `에 새 작가를 입력하고, 이후 목록에서 바뀐 값을 본다. 없는 번호면 아무것도 입력받지 않고 `N번 명언은 존재하지 않습니다.`를 본다.

부모 스펙: `.scratch/wise-saying-console-app/spec.md`
